# Sound pack licenses and provenance

This file covers the **audio files** only. typebud's code is MIT. The
question here is whether each recording may ship inside an MIT app, and what
attribution it needs.

Rules applied:

* **Bundle by default** only audio under MIT, CC0 or CC-BY, whose license
  can be traced to the person or project that published it.
* **GPL audio** ships only as a separately licensed data pack (its own folder,
  its own LICENSE, `bundle: "optional-gpl"` in `packs/index.json`), never inside
  the app binary or installer. The user decides whether to distribute it at
  all. See "Decisions needed" at the end.
* **Unknown provenance** (no license, "community" credit with no source,
  sampled from a commercial product, unspecified Creative Commons license) is
  excluded, even when it sits inside an MIT-licensed repository. A repo's code
  license does not show that its contributors had the right to license
  recordings they did not make.

Every bundled pack folder has a `LICENSE` file holding the attribution, the
upstream repo + commit, and the full upstream license text. `pack.json` repeats
`license`, `attribution` and `source`. The app must show `attribution` in its
credits screen (see FORMAT.md section 6).

All imports are reproducible:
`python3 scripts/sounds/import_pack.py defaults --sources <dir>`
(recipes: `scripts/sounds/default_packs.json`). The output was verified to be
byte-identical across rebuilds.

### Provenance notes on the bundled packs

* **kbsim (MIT).** The repository's single `LICENSE.md` (MIT, "Copyright (c)
  Thomas Lai") covers the whole repo, including `src/assets/audio/`. Nothing in
  the repo credits anyone else for the recordings, so they are taken to be the
  author's. Others have read it the same way: Keyboard Sounds Pro, Keyboard
  Sounds and Mechvibes redistribute these exact files (checksums match) under
  "Audio samples from https://github.com/tplai/kbsim" + MIT, and the Thock
  registry lists every tplai pack as MIT with a link to kbsim's LICENSE.md.
  Residual risk: kbsim never says "I recorded these". That is acceptable for
  MIT-by-repository, but noted here.
* **Keyboard Sounds Pro G915 (MIT).** The profile's author field is "Keyboard
  Sounds", the project's own name, so the recordings are by the maintainer,
  Nathan Fiscaletti. The same WAV files (checksums match) are also in his
  GPL-3.0 project `nathan-fiscaletti/keyboardsounds`. Because the copyright
  holder also publishes them under MIT in keyboardsounds-pro, we take the MIT
  grant.
* **bucklespring (GPL-2.0).** The repo's only license is GPLv2, and the README
  ("Copyright 2016 Ico Doornekamp") says it emulates "my old faithful IBM
  Model-M space saver" and that "the sound of each key has carefully been
  sampled". No "or any later
  version" grant appears anywhere, so it is recorded as `GPL-2.0-only`. That is
  the conservative reading. (Strictly, GPLv2 §9 lets a recipient choose any
  version when none is specified. It doesn't matter for the decision below.)
* **bubble-pop (CC0).** Synthesized deterministically from damped sines and a
  short noise tick. No recorded material.

## Decisions (resolved)

1. **Model M (GPL-2.0-only):** not shipped. The MIT-licensed `buckling-spring` (kbsim) pack covers the sound.
2. **Typewriter:** not shipped; `alps-blue` is the closest vintage sound in the set.
3. **type-joy "Unknown" keyboard:** not imported (recorder unknown).
4. **Attribution:** the app's settings window has a Credits section listing each pack's `attribution` text; each pack folder keeps its LICENSE file.
